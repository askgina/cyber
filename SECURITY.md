# Security policy

To report a vulnerability in Cyber’s code or hosted service, use [GitHub private vulnerability reporting](https://github.com/askgina/cyber/security/advisories/new). Include the affected component or URL, the impact, and enough information for maintainers to investigate. Do not include credentials, private records, or other unnecessary sensitive data. Please do not open a public issue for a vulnerability.

This channel is for Cyber itself. If an incident affects an organization covered by the feed, contact that organization or the relevant authority instead.
